# Tailpreview v0.1.0

The first public Tailpreview release turns already-running localhost services
into temporary HTTPS previews that remain private to your Tailscale tailnet.

## Highlights

- Route a frontend, API, assets, and WebSockets through one HTTPS origin.
- Keep every upstream restricted to `localhost`, `127.0.0.1`, or `::1`.
- Run up to ten concurrent worktree previews with stable port reuse.
- Expire idle previews after 24 hours and enforce a seven-day maximum age.
- Evict the least recently used inactive preview when the pool is full.
- Protect active requests and pinned previews from eviction.
- Roll back Caddy and Tailscale changes when health or final URL checks fail.
- Use stable JSON and non-interactive commands from coding agents.
- Install the bundled Tailpreview Codex skill as a plugin.

Tailpreview uses Tailscale Serve and never Tailscale Funnel. It does not start
or stop application services, modify tailnet policy, expose non-loopback
targets, or persist sensitive request data.

## Install on macOS

```bash
brew install jhumanj/tap/tailpreview
tailpreview doctor
tailpreview service install
```

Linux `amd64` and `arm64` archives are attached below. Every archive is covered
by `checksums.txt`.

See the [README](https://github.com/JhumanJ/tailpreview#readme) for routing,
project configuration, security boundaries, and skill installation.
