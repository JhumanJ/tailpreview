# Tailpreview v0.1.1

This patch replaces the unsigned Homebrew cask with a cross-platform Homebrew
formula. On macOS, `brew install` now links the CLI normally without requiring
users to bypass a Gatekeeper quarantine prompt.

```bash
brew install jhumanj/tap/tailpreview
tailpreview doctor
```

The formula selects the correct prebuilt archive for macOS or Linux and for
Intel or ARM, installs Caddy as a dependency, verifies the release checksum,
and links `tailpreview` into Homebrew's `bin` directory.

GitHub Actions were also updated to their current Node 24-compatible major
versions.
