# Contributing

Thank you for helping improve Tailpreview.

1. Open an issue for material behavior or security-boundary changes.
2. Keep changes focused and add regression tests.
3. Run `make check`.
4. Update public documentation and the JSON contract when relevant.
5. Never use a real tailnet in automated tests.

Security-sensitive proposals — Funnel, non-loopback targets, credential
handling, tailnet administration, or proxy-level cookie rewriting — require an
explicit design review before implementation.

By contributing, you agree that your contribution is licensed under MIT.
