# Security policy

Security fixes are accepted for supported releases and the current development
line.

Please do not open a public issue for vulnerabilities that could expose local
services, secrets, tailnet configuration, or request data. Use
[GitHub private vulnerability reporting](https://github.com/JhumanJ/tailpreview/security/advisories/new).

Include the affected version/commit, operating system, Tailscale and Caddy
versions, reproduction steps, and impact. Do not include real credentials,
signed URLs, or production request data.
